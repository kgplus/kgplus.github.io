# KG Plus Architecture Studio website

## Package contents
- `index.html`, `about.html`, `services.html`, `projects.html`, `blog.html`, `contact.html`
- `services/`: six individual service pages
- `ar/`: Arabic RTL versions of main pages and individual service pages
- `assets/logo.jpg`: supplied studio logo
- `assets/style.css`: responsive styling
- `assets/main.js`: preloader, back-to-top, enquiry form and popup behavior

## Run locally
Open `index.html` in a browser, or upload the folder contents to your web host. The site uses Bootstrap 5.3.3 and Font Awesome from CDNs, so an internet connection is needed for those libraries and remote imagery.

## Before publishing
1. Replace illustrative Unsplash photos and placeholder portfolio items with approved KG Plus project photography.
2. Confirm the final brand spelling and legal company name.
3. Set up a real form endpoint if you want submissions delivered without opening the visitor's email application. Current forms prepare a message via `mailto:info@kg-intl.com`.
4. Update canonical URLs and add a production sitemap/robots file for the final hosting structure.
5. Test all pages and contact details on the production domain.
